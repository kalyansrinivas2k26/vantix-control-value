# Decision Register

| Decision ID | Decision | Basis | Consequence |
|---|---|---|---|
| DR-01 | Preserve Commitment Assurance rather than rebuild Control Value. | Protected authoritative baseline and migration rule. | Behaviour must remain traceable through regression evidence. |
| DR-02 | Share control patterns, not domain calibration. | Each module has different decisions, CTQs and tolerances. | No shared thresholds or aggregate DPMO. |
| DR-03 | Separate technical restoration from relationship recovery. | A functioning service does not prove restored customer confidence. | Service Recovery keeps two independent statuses. |
| DR-04 | Treat Customer Momentum as an evidence-driven learning loop, not churn prediction. | Current evidence supports change, hypothesis, intervention and measured outcome only. | No predictive-accuracy claim. |
| DR-05 | Label the integrated repository Portfolio Preview. | Positive synthetic paths exist, but mandatory security and resilience gates remain open. | No production readiness or Verified Release wording. |
| DR-06 | Keep public workflow exports inactive and credential-free. | Minimize accidental consequence and metadata exposure. | Import requires controlled owner action. |
