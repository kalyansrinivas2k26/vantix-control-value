# Six Sigma / Measurement Boundary

Control Value does **not** reuse Flow Integrity's DPMO model.

Relevant CTQs include:
- promise completeness;
- evidence strength/completeness;
- outcome-verification state;
- SLA adherence;
- aging/retry/escalation history;
- closure integrity and reopen/dispute behavior.

## Claim rule

Do not publish DPMO, Sigma or Cpk merely because a workflow contains quality checks.

A valid DPMO claim requires the unit, defect definition, opportunities per unit, observed dataset, defect count, numerator and denominator.

Cpk additionally requires stable continuous process data and specification limits.

The current Portfolio Preview therefore receives measurement-design credit, not production capability credit.
