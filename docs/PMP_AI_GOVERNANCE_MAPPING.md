# PMP / PMI AI Governance Mapping

This is a governance mapping, not PMI endorsement.

| Principle | Control Value implementation |
|---|---|
| Value / benefits | commitment closure is tied to intended customer outcome, not task completion |
| Governance | deterministic policy governs allowable action and closure |
| Stakeholder accountability | customer-success, admin/delivery and human-approval roles remain distinct |
| Risk | likelihood, impact, priority, evidence confidence and escalation are explicit |
| Human oversight | consequential action/closure requires human authority |
| Decision authority | AI explains/critiques; code and people decide |
| Transparency | evidence, reason codes, routes and audit context are inspectable |
| Responsible AI | bounded output, critique, deterministic validation and fail-closed handling |
