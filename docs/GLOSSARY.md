# Vantix Control Value Terminology

| Term | Meaning in this project |
| --- | --- |
| Customer Success Manager | Business actor who owns or verifies customer-outcome work. Existing `CSM_` action codes refer to this role. |
| Certified ScrumMaster | Portfolio owner's professional credential and delivery discipline. It is not the Customer Success Manager actor. |
| Human approval fixture | Fabricated decision data used to validate policy and payload-binding rules. It is not a decision collected by n8n. |
| AI diagnosis fixture | Pre-authored structured replay used to validate the contract. It is not a live Gemini response. |
| Technical verification | Independent system evidence that the intended technical state exists. |
| Customer-use verification | Authorized evidence that the customer actually achieved or used the promised result. |
| Closure | Human-authorized final state available only after the required verification and policy conditions pass. |
